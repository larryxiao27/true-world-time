# 真世界时 1.0.0

面向个人 Mac 使用的独立时钟应用。

- 真实时间与系统时间双时钟，支持 12／24 小时制。
- 后台静默运行、手动打开设置、可选登录启动。
- CPU、App 内存占比与基础硬件信息按需显示。
- 成品界面统一使用「真世界时」，移除故障注入、样本编号、内部日志路径及开发阶段提示。
- 中文校时状态、清晰的系统快慢说明与最近校时时间。

## 安装

适用 Apple Silicon、macOS 15+。退出旧版后，用 DMG 中的应用覆盖「应用程序」里的现有版本。再次手动打开可显示设置。

保留原应用身份以兼容已添加组件和设置。内部包名可能仍为 `TrueWorldTimeProbe.app`，Finder 中的本地化名称为「真世界时」。
